# RC Remote Controller - Copilot Instructions

## Comment Style Convention

**Scope:** All files in `app/src/**`

**Rule:** Use only block comments `/* */` for all inline, block, and file header comments. Single-line comments `//` are not permitted in this directory.

### Why
- Consistency across the codebase (see `instruction.md`)
- Block comments integrate better with Doxygen-style documentation
- Aligns with established project standards

### What This Means
✅ **Correct:**
```c
/* This is a single line comment */

/* This is a multi-line comment
   that spans several lines
   explaining the logic */

/**
 * @brief Function documentation in Doxygen style.
 * @param value Input parameter.
 * @return Status code.
 */
int my_function(int value) {
    /* Process the value */
    return 0;
}
```

❌ **Incorrect:**
```c
// This is NOT allowed in app/src/

// Even single-line comments must use /* */
```

### Exceptions
- Generated code in `app/ui/` is excluded (automatically generated by EEZ Studio)
- Other directories outside `app/src/` may have different conventions

### When This Applies
- New code written in `app/src/`
- Modifications to existing code in `app/src/`
- Refactoring within `app/src/`
